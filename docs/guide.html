ШАГ 2 Установи зависимости

Создай виртуальное окружение и поставь пакеты

ШАГ 3 Получи API ключи

Три ключа, которые нужны для работы

Ключ Где получить Тип
TELEGRAM_BOT_TOKEN @BotFather в Телеграме
Напиши /newbot → дай имя → скопируй токен 		Обязательно
IO_NET_API_KEY cloud.io.net
Войди → API Keys → Create New Key 		Обязательно
ALLOWED_USER_IDS @userinfobot в Телеграме
Напиши любое сообщение — получишь свой ID 		Обязательно
TOKEN_STORE_PASSWORD Придумай сам
Любой надёжный пароль для шифрования хранилища 		Обязательно

ШАГ 4 Заполни файл .env

Скопируй шаблон и вставь свои ключи

bash # Скопировать шаблон
$ cp .env.example .env

# Открыть и заполнить
$ nano .env
.env TELEGRAM_BOT_TOKEN=7012345678:AAHxxxxxxxxxxxxxxxxxxxxxx
IO_NET_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxx
ALLOWED_USER_IDS=123456789
TOKEN_STORE_PASSWORD=my_super_secret_pass_2024

# Остальное можно не менять:
OLLAMA_BASE_URL=http://localhost:11434
OLLAMA_MODEL=llama3.2
IONET_BASE_URL=https://api.intelligence.io.solutions/api/v1
IONET_MODEL=meta-llama/Llama-3.3-70B-Instruct
DASHBOARD_PORT=3000
⚠️
Важно! Файл .env уже в .gitignore — он никогда не попадёт в git. Не делись им ни с кем!

ШАГ 5 Запусти Ollama Опционально

Локальный AI — данные не покидают твой сервер

bash # 1. Установить Ollama
$ curl -fsSL https://ollama.com/install.sh | sh

# 2. Скачать и запустить модель
$ ollama run llama3.2

# Модель скачается автоматически (~2GB)
# После скачивания Ollama будет работать на localhost:11434
💡
Зачем нужен Ollama?
Команда /local использует Ollama для обработки чувствительных запросов. OS-команды и пароли никогда не отправляются в облако.
Если Ollama не нужен — просто пропусти этот шаг. Облачный /ai работает без него.

🔒 Безопасность

Что нужно знать о защите

🚫
.env не в git
Файл с ключами добавлен в .gitignore — он никогда не попадёт в репозиторий. Никогда не делись файлом .env.
🔐
AES-256 шифрование
Токены дочерних ботов шифруются с помощью пароля TOKEN_STORE_PASSWORD. Без пароля — не расшифровать.
🛡️
Whitelist доступа
Только Telegram ID из ALLOWED_USER_IDS могут управлять ботом. Все остальные получат "⛔ Access denied".
🏠
Локальный AI
Ollama обрабатывает чувствительные запросы на твоём сервере. Пароли и OS-команды никогда не уходят в облако.
